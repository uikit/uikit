JavaScript Options

Option Value Default Description
targets CSS selector > * The element(s) to toggle.
active Number false Index of the element to open initially.
collapsible Boolean true Allow all items to be closed.
multiple Boolean false Allow multiple open items.
transition String ease The transition to use.
animation Boolean, String true Set to `false` to reveal items directly. When using `switcher-connect`, accepts space-separated animation names and an optional comma-separated animation-out value. Connected containers can override this with `uk-switcher-animation`.
duration Number 200 The animation duration.
offset Number 0 Offset added to scroll top.
switcher-connect CSS selector false Related switcher items container. Children are toggled in sync with the active accordion item.
